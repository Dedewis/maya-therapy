# Dr. Maya Reynolds — Therapy Website

A responsive therapy practice website designed for Dr. Maya Reynolds, a licensed clinical psychologist based in Santa Monica, California.

The project redesigns the provided reference website with a warm, calm, and approachable visual identity while keeping the original site's overall structure and responsive experience.

## Live Website

https://maya-therapy-lovat.vercel.app/

## GitHub Repository

https://github.com/Dedewis/maya-therapy

## About the Project

The website was created as a frontend redesign project using the provided Dr. Maya Reynolds profile as the primary source for:

- Practice information
- Client focus
- Areas of expertise
- Therapeutic approach
- Services
- Location and telehealth availability
- Office details

The design uses a warm neutral palette, editorial-style imagery, responsive layouts, and clear content hierarchy to create a calm and trustworthy experience for prospective clients.

## Key Sections

- Hero section with primary consultation CTA
- Who I Work With
- Areas of Focus
- Services
- Therapeutic Approach
- About Dr. Maya Reynolds
- Our Office
- Consultation CTA
- Frequently Asked Questions
- Responsive footer

## Features

- Responsive desktop and mobile layouts
- Mobile navigation menu
- Smooth section-based navigation

- FAQ accordion using native HTML details/summary
- Responsive consultation CTAs
- Optimized production build

## Getting Started

Clone the repository:
bash
git clone https://github.com/Dedewis/maya-therapy.git
cd maya-therapy



Install dependencies:

npm install

Run the development server:

npm run dev

Open:

http://localhost:3000
Production Build

To create a production build:

npm run build

The project has been tested with a successful Next.js production build.

Design Approach

The design direction was intentionally kept warm, minimal, and professional. The visual system combines soft neutral backgrounds with sage green, terracotta, and charcoal accents.

The content and imagery were adapted around Dr. Maya's profile to communicate a sense of calm, trust, and accessibility while maintaining a clear and easy-to-navigate structure.
